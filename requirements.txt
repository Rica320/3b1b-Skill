# Exact versions the examples in this repository were rendered and verified
# against (Python 3.13.7 — see .python-version). Regenerate with:
#   pip freeze > requirements.txt
#
# IMPORTANT: the package is `manimgl` (3b1b/manim), NOT `manim` (Manim
# Community Edition). They are unrelated libraries with incompatible APIs.
#
# `scikit-learn` is needed only by examples/gans/prepare_assets.py, which
# fetches the Olivetti faces dataset. The `pyobjc-*` pins carry a platform
# marker because they are macOS-only and abort the install on Linux.
#
# `kokoro-onnx` and `soundfile` are the narration toolchain (scripts/tts.py).
# The 353MB of Kokoro model weights are NOT a pip package -- fetch them with
# `bash skills/3b1b-math-animation/scripts/setup_env.sh --tts`, which puts
# them in ~/.cache/kokoro. The other TTS engines are deliberately absent:
# `elevenlabs` and `openai` are API clients you only need if you have a key,
# and `chatterbox-tts` pulls ~2.5GB of torch for local voice cloning. Install
# whichever you actually use.
#
# Not installable with pip, and required: ffmpeg (encoding, the decode step in
# verify_render.py, and every join/mix/measurement in the audio pipeline), a
# LaTeX distribution providing dvisvgm and dsfont.sty (for Tex()), and the CMU
# Serif font. On Debian/Ubuntu these are handled by
# skills/3b1b-math-animation/scripts/setup_env.sh; on macOS see the README.
